🚀 Backend CRUD API - Komik Node.js & Sequelize

Proyek ini adalah implementasi RESTful API untuk pengelolaan data (CRUD - Create, Read, Update, Delete) komik menggunakan **Node.js**, **Express.js**, **Sequelize ORM**, dan **PostgreSQL**. Proyek ini dikembangkan untuk memenuhi tugas praktikum pemrograman web.

---

## 🛠️ Tech Stack
* **Language:** JavaScript (Node.js)
* **Framework:** Express.js
* **ORM:** Sequelize
* **Database:** PostgreSQL
* **Environment Management:** dotenv

---

## ⚙️ Konfigurasi Proyek (.env)
Pastikan kamu memiliki file `.env` di direktori *root* proyek dengan konfigurasi seperti berikut sebelum menjalankan aplikasi:

```env
DB_NAME=komik
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
PORT=3000
